MineSync Sim is a synthetic research prototype for studying interoperable coordination between autonomous haul trucks from multiple suppliers, loaders/LHDs, and manual mining vehicles. Built with Python, Mesa, and Streamlit, it compares local priority rules, central traffic management, and broker/mediator-based coordination using seeded, repeatable scenarios.
The dashboard includes scenario building, live simulation, coordination comparison, situational awareness, robustness testing, and KPI sensitivity analysis. It measures productivity, waiting time, throughput, queue length, resource utilisation, conflicts, deadlocks, and recovery time.
